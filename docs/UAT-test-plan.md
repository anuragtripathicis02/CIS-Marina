## 1. Scope & Execution Methodology
The UAT Test Plan validates 25 core end-to-end user journeys spanning public marketing, charter booking, customer portal, vessel maintenance, marina slip management, CRM sales pipeline, natural language AI analytics, and enterprise branch settings.
